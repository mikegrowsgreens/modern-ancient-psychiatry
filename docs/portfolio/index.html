The Problem

Solo practitioner. No web presence. Patients can't find her.

A board-certified Psychiatric Mental Health Nurse Practitioner was launching her solo integrative psychiatry practice in Arizona. She needed a professional web presence before opening to patients — something that communicated clinical credibility while feeling warm, intentional, and approachable. No Squarespace template was going to capture that.

01 — Design System

A visual identity built from the practice's philosophy

The name "Modern Ancient Psychiatry" set the tone: clinical rigor paired with ancient healing wisdom. I designed a system that reads as calming, premium, and deeply human — not sterile.

Typography

Cormorant Garamond (serif) for headings, Source Sans 3 (sans) for body. The pairing says "medical professional who cares about the human experience." Light weights throughout for an airy, unhurried feel.

Key Visual Decisions

  • Dark background feels calming and premium — not clinical white
  • Gold accents add warmth without being loud (dividers, headings, CTAs)
  • Hero uses a full-viewport Ken Burns animation (25s CSS keyframe) with frosted-glass circle overlay (backdrop-blur-md)
  • All animations are additive — content always visible for SSR and no-JS compatibility

03 — Content Architecture

Copy and code are completely separate

Every piece of text on the site — hero copy, service descriptions, fee schedules, policy sections, FAQ answers — lives in typed TypeScript data files. Components just render. This is the pattern that makes the site maintainable.

src/content/ ← All copy lives here home.ts Hero, philosophy, FAQ, video, CTA about.ts Bio, personal, meditation, approach services.ts 7 services, fees, 9 policies (typed) contact.ts Contact page copy shared.ts Nav, footer, social links src/components/ ← Purely presentational sections/ Hero, Philosophy, FAQ, BookingCTA... ui/ Button, Accordion, FadeIn, ServiceCard layout/ Header, Footer, MobileBookingBar src/app/ ← Next.js App Router page.tsx Home (composes 7 sections) about/page.tsx About services/page.tsx Services contact/page.tsx Contact api/contact/ Form → n8n webhook

Why this matters

  • Client can update any text by editing a single .ts file — no component knowledge needed
  • Content is type-checked at build time — typos in field names caught before deploy
  • Services, fees, and policies are structured data, not hardcoded strings in JSX
  • Adding a new FAQ or service is adding one object to an array

Why This Matters

End-to-end, one person

Design + development, no handoff

No Figma file to implement. I designed the visual identity (typography, palette, layout, animations) and built the frontend in the same pass. Design decisions were made in code, not in a separate tool.

Production, not a mockup

This is a real website for a real business. It's indexed by Google, serves actual patients, and has been running in production since day one. Not a tutorial project.

Content architecture for non-developers

The client is a psychiatrist, not a developer. The content layer means she can update any text on the site by editing plain data files. No CMS cost, no Squarespace lock-in, no drag-and-drop limitations.

AI-assisted development

Built with Claude Code. I directed the design, content structure, and architecture. AI accelerated the implementation. This is how I work — not a novelty, a workflow.

Design details that matter
  • FadeIn animations are purely additive — content is always visible even without JS
  • Logo background removed with ImageMagick; footer uses CSS brightness-0 filter for dark silhouette on gold
  • Philosophy section renders 3 statements over a decorative background frame — middle statement in accent purple italic
  • Emergency disclaimer banner on every page — required for mental health practices
  • Skip-to-content link, semantic HTML, ARIA labels, keyboard navigation throughout
  • Mobile booking bar persists at bottom of viewport — always one tap from contact
